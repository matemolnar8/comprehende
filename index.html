Comprehende

Pay attention where it counts.

The agent writes the code. Comprehende gives you the why and the what.

Agents write faster than we can understand

  • Pull requests list files alphabetically
  • Tests pass, so we approve
  • Cognitive surrender. No view of our own
  • Comprehension debt. Invisible until something breaks

Hand off the code, keep the understanding

Surrender

  • Agent decides what the change is
  • No view of your own
  • Approved, not understood

Offloading

  • Agent writes the code
  • You get the why and the what
  • You check them against the diff

A review assistant for any git diff

  • Your agent groups the changes by review concern
  • Related groups stay together
  • The UI shows each group next to the real diff

Who writes what

Git

  • The diff
  • Full files
  • Blame

Your agent

  • Groups
  • Why and what
  • Things to check
  • Sources

Goals

  • Accuracy. The diff comes from git
  • Coverage. Every change is in a group
  • Fixed UI. Only the data changes
  • Local. No hosted service, no account
  • Plain words. Simplified Technical English

Non-goals

  • Review for you. Understanding stays your job
  • Judge. No approve, reject, or score
  • Replace git. No stored patches
  • Know your tools. Bitbucket, Jira, anything your agent can read
  • Generate UI. The model never draws a screen

Start with the whole change

  • Why and what. Before any diff
  • Things to check. Where code and sources disagree
  • Reading order. Groups, split into parts

Then one group at a time

  • One concern. Why it exists, what it does
  • Attention. The one call only you can make
  • The real diff. With a note on each file

Go past the diff

  • Full file or blame. At base or head
  • Blame. Commit, author, date
  • In this review. Commits from this change

Also in the UI

  • Focus and notes. Key lines open first
  • Ask agent. Send a question to your coding agent
  • Sources. Tickets, comments, commits, transcripts
  • Refresh. Keeps groups, shows what changed
  • Mechanical groups. Renames and generated files to skip
  • Images. Side by side, slider, pixel diff
  • Keyboard. [ ] groups, j k files, v viewed
  • Links. Every view has a URL
  • Any screen. Phone, light, dark

Install and use

# once, in any repo
npx skills add matemolnar8/comprehende

# in your coding agent, name what to review
/comprehende PR 154
/comprehende the commits from the last turn
/comprehende feature/auth against main

Needs Node.js 24+ and git, on macOS, Linux, or Windows.
